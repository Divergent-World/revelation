# Historical book-build records

These files document the earlier `_book-build` process. They are historical reference material, not the current publishing source of truth.

The repository's `content/*.json` files are canonical for scripture, scene, caption, and metadata content. The generators under `publishing/book-source/` and the portable IDML under `publishing/indesign/` are the maintained publishing sources.

The 180-page PDFs from the historical build are excluded. The only official finished PDF is the 182-page `REVELATION_web.pdf` staged under `publishing/editions/`.
